PushBox 安装

填完点「保存并启动」，服务端会立刻接着启动，不需要重启容器。带 * 的必填，其余留空即用默认值。

1 · 数据库

消息与频道都存在 MySQL 里（8.0 及以上）。库不存在时安装会顺手建一个。

库和 PushBox 在同一台机器上时，也别填 127.0.0.1：容器里的 127.0.0.1 是容器自己，要填局域网 IP。

2 · 图片与头像存哪里

默认存在 PushBox 自己的数据目录里，不需要额外的存储服务。

容器里是 /app/data/media，把 /app/data 挂到 NAS 的文件夹上就能保住图片。

口令本身不存盘，服务端用它派生出加密密钥，只保存校验信息。忘了它就解不开已存的图片，且无法重设。

内网地址默认一律不抓（防 SSRF），所以图床在内网时必须在这里点名。写 host 或 host:port，逗号分隔，不带 http:// 与路径。

3 · 管理台与服务

管理台用来看频道、设备与搜索消息。留空即不启用（登录返回 403）。

登录时只填这一个口令，没有用户名。签名密钥由服务端自动生成，不需要你管。

/healthz 与 /actuator/** 默认只允许本机访问；要从别的机器抓监控指标就在这里写网段。
