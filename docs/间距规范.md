# PushBox 间距规范

## 设计原则

- **基准单位**：8dp（对应1x密度下的8px）
- **所有间距必须是8的倍数或一半**：即 {4, 8, 12, 16, 24, 32, 48, 64}
- **避免使用奇数或非标准值**：如 6、10、14、20 等应替换为最接近的标准值

## 间距层级

| 层级 | 值 | 用途 |
|------|-----|------|
| XS | 4dp | 紧密元素内部间距（图标与文字、标签之间） |
| SM | 8dp | 常规内边距、列表项垂直间距、按钮内边距 |
| MD | 12dp | 中等间距（较少使用，用于需要比SM稍大但不到LG的场景） |
| LG | 16dp | 页面内边距、卡片外边距、Section间距 |
| XL | 24dp | Section标题间距、对话框内边距 |
| XXL | 32dp | 页面级分组间距、空状态上下边距 |
| XXXL | 48dp | 超大空白区域（欢迎页、错误页） |

## 常见场景

### 1. 列表项
- 垂直间距：`Arrangement.spacedBy(8.dp)`
- 水平内边距：`padding(horizontal = 16.dp)`
- 垂直内边距：`padding(vertical = 8.dp)`

### 2. 页面容器
- 外层内边距：`padding(horizontal = 16.dp, vertical = 12.dp)`
- Section间距：`Arrangement.spacedBy(16.dp)`

### 3. 卡片/气泡
- 内边距：`padding(12.dp)` 或 `padding(16.dp)`
- 元素间距：`Arrangement.spacedBy(8.dp)`

### 4. 按钮/操作区
- 水平间距：`Arrangement.spacedBy(8.dp)`
- 垂直间距：`padding(vertical = 8.dp)`

### 5. 图标与文字
- 间距：`padding(start = 8.dp)` 或 `Arrangement.spacedBy(4.dp)`

## 禁止使用的值

以下间距值应在代码审查中被替换：
- ❌ 1dp, 2dp → ✅ 4dp
- ❌ 6dp → ✅ 8dp
- ❌ 10dp → ✅ 8dp 或 12dp
- ❌ 14dp → ✅ 12dp 或 16dp
- ❌ 20dp → ✅ 16dp 或 24dp

## Android 实现

在 `MainActivity.kt` 中定义常量：

```kotlin
private object Spacing {
    const val XS = 4   // 紧密间距
    const val SM = 8   // 标准间距
    const val MD = 12  // 中等间距
    const val LG = 16  // 大间距
    const val XL = 24  // 超大间距
    const val XXL = 32 // 页面级间距
    const val XXXL = 48 // 特大间距
}
```

## Windows 实现

在 `Tokens.xaml` 中定义资源：

```xml
<Thickness x:Key="Spacing.XS">4</Thickness>
<Thickness x:Key="Spacing.SM">8</Thickness>
<Thickness x:Key="Spacing.MD">12</Thickness>
<Thickness x:Key="Spacing.LG">16</Thickness>
<Thickness x:Key="Spacing.XL">24</Thickness>
<Thickness x:Key="Spacing.XXL">32</Thickness>
<Thickness x:Key="Spacing.XXXL">48</Thickness>
```
