# PushBox 微交互反馈规范

## 设计原则

- **即时反馈**：用户操作后100ms内给予视觉/触觉反馈
- **适度克制**：只在关键操作提供触觉反馈，避免过度干扰
- **一致性**：同类操作使用相同的反馈模式

## 触觉反馈（Haptic Feedback）

### 启用场景

| 场景 | 反馈类型 | 说明 |
|------|---------|------|
| 按钮点击 | Light | 主要操作按钮（发送、确认、删除等） |
| 开关切换 | Medium | Switch状态改变 |
| 列表项长按 | Medium | 弹出菜单前的触觉提示 |
| 下拉刷新 | Heavy | 触发刷新时的强反馈 |
| 错误提示 | Error | 表单验证失败、网络错误 |
| 成功提示 | Success | 消息发送成功、保存成功 |

### Android 实现

```kotlin
val haptic = LocalHapticFeedback.current

// 轻触反馈（按钮点击）
Button(onClick = {
    haptic.performHapticFeedback(HapticFeedbackType.TextHandleMove)
    // 业务逻辑
})

// 中等反馈（开关切换）
Switch(checked = value, onCheckedChange = {
    haptic.performHapticFeedback(HapticFeedbackType.LongPress)
    value = it
})

// 强反馈（下拉刷新）
haptic.performHapticFeedback(HapticFeedbackType.DragStart)
```

### 禁止场景

- ❌ 普通文本选择
- ❌ 滚动列表
- ❌ 页面切换动画
- ❌ 自动播放内容

## 视觉反馈

### 按钮状态

```kotlin
Button(
    onClick = { ... },
    modifier = Modifier
        .clickable(interactionSource = remember { MutableInteractionSource() }, indication = rememberRipple())
)
```

### 列表项悬停/点击

- 使用 `combinedClickable` 替代 `clickable`
- 添加 `indication = rememberRipple()` 波纹效果
- 长按时显示半透明遮罩层

### 加载状态

- 按钮点击后立即进入 `loading` 状态
- 显示旋转进度条或骨架屏
- 超时3s后显示错误提示

## 动画反馈

### 页面过渡

- 左右滑入/滑出：300ms ease-in-out
- 淡入淡出：200ms ease-out
- 缩放出现：150ms spring

### 元素出现

- 消息气泡：从底部滑入 + 淡入，200ms
- 通知横幅：从顶部滑入，250ms spring
- 对话框：中心缩放出现，150ms

## 音频反馈（可选）

仅在以下场景使用：
- 消息接收提示音（可关闭）
- 错误提示音（短促"嘟"声）
- 成功提示音（轻柔"叮"声）

## 性能要求

- 触觉反馈延迟 < 50ms
- 视觉动画帧率 ≥ 60fps
- 避免在低端设备上启用复杂动画

## 无障碍考虑

- 触觉反馈强度可在系统设置中调节
- 提供"减少动画"选项
- 所有视觉反馈必须有文字替代方案
