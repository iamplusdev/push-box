# PushBox 字体规范

本文档定义三端统一的字体层级系统、字号基准、行高比例与字体族选择，确保中英文混排的可读性与视觉一致性。

## 设计原则

1. **基准字号 15sp/px**：正文使用 15 单位字号，这是移动端与桌面端都能舒适阅读的最小值
2. **行高 1.53×**：正文行高 23 ÷ 15 ≈ 1.53，符合中文排版的黄金比例（1.5–1.6）
3. **四档标题**：H1=20, H2=18, H3=16, H4+=15，每级差 2pt，避免跳跃过大
4. **等宽字体仅用于代码**：日志、命令、token 必须用 Consolas/等宽字体，其他场景禁用
5. **中英混排优先**：西文字体选无衬线体，中文字体选微软雅黑/思源黑体，不单独指定英文字体

## 字体层级表

| 用途 | 字号 | 行高 | 字重 | 示例场景 |
|------|------|------|------|----------|
| **H1** | 20 | 28 | Bold | 页面大标题、空状态主文案 |
| **H2** | 18 | 25 | Bold | 设置页分组标题、频道治理标题 |
| **H3** | 16 | 22 | Medium/SemiBold | 会话名称、次级标题 |
| **Body** | 15 | 23 | Normal | 消息正文、说明文字 |
| **Small** | 13 | 18 | Normal | 摘要、辅助说明、列表项副文本 |
| **Label** | 12 | 16 | Normal/Medium | 时间戳、角标、提示文字、按钮小字 |
| **Code** | 13 | 18 | Normal (Monospace) | 代码块、恢复码、设备 ID、curl 命令 |

### 字号使用规则

- **禁止出现 14sp/px**：要么 13（Small），要么 15（Body），14 是尴尬的中间态
- **时间戳统一 12sp**：会话行的右侧时间、消息气泡内的时间都必须是 12
- **摘要/副文本统一 13sp**：比正文小一档，但比标签大一档
- **标题只分四档**：不要为每个业务场景发明新字号，套用 H1–H4

## 字体族选择

### Android

```kotlin
// UI 文本：系统默认（Roboto + Noto Sans CJK）
FontFamily.Default

// 代码/等宽：系统默认等宽
FontFamily.Monospace
```

**理由**：Android 系统字体已针对屏幕渲染优化，无需额外指定。Material Design 推荐使用系统默认。

### Windows

```csharp
// UI 文本：Segoe UI（西文）+ Microsoft YaHei UI（中文）
new FontFamily("Segoe UI, Microsoft YaHei UI")

// 代码/等宽：Consolas（西文）+ Microsoft YaHei UI（中文注释）
new FontFamily("Consolas, Microsoft YaHei UI")
```

**理由**：
- Segoe UI 是 Windows 原生 UI 字体，ClearType 渲染最佳
- YaHei UI 是专为屏幕优化的中文版型，比传统 YaHei 更清晰
- Consolas 是等宽字体中的经典，适合代码与 token 显示

### Web（管理台）

```css
/* UI 文本 */
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans SC", sans-serif;

/* 代码 */
font-family: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace;
```

## 行高与间距

### 行高公式

```
行高 = 字号 × 1.53（向上取整到偶数）
```

| 字号 | 计算值 | 实际采用 | 原因 |
|------|--------|----------|------|
| 20 | 30.6 | 28 | H1 紧凑些更好看 |
| 18 | 27.5 | 25 | H2 同上 |
| 16 | 24.5 | 22 | H3/会话名 |
| 15 | 23.0 | 23 | Body 严格遵循 |
| 13 | 19.9 | 18 | Small 略收紧 |
| 12 | 18.4 | 16 | Label 更紧凑 |

### 段落间距

- **块级元素之间**：4px（`BlockGap = 4`）
- **列表项之间**：2px（`ListGap = 2`）
- **引用块缩进**：8px（`QuoteIndent = 8`）
- **代码块内边距**：8px（`CodePadding = 8`）

## 平台实现

### Android (Theme.kt)

```kotlin
private val PushBoxTypography = Typography(
    // H1-H4 在 Markdown 渲染时动态指定，此处只定义常用样式
    titleMedium = TextStyle(
        fontSize = 16.sp,      // H3 / 会话名
        fontWeight = FontWeight.Normal,
        lineHeight = 22.sp
    ),
    bodyLarge = TextStyle(
        fontSize = 15.sp,      // Body
        lineHeight = 23.sp     // 1.53×
    ),
    bodyMedium = TextStyle(
        fontSize = 13.sp,      // Small / 摘要
        lineHeight = 18.sp
    ),
    labelSmall = TextStyle(
        fontSize = 12.sp,      // Label / 时间戳
        lineHeight = 16.sp,
        color = Color(0xFF8A8A8A)
    ),
)
```

**Markdown 标题映射**（MainActivity.kt）：
```kotlin
fontSize = when (block.level) {
    1 -> 20.sp  // H1
    2 -> 18.sp  // H2
    3 -> 16.sp  // H3
    else -> 15.sp  // H4+
}
```

### Windows (MarkdownStyle.cs)

```csharp
public const double BodySize = 15;
public const double BodyLine = 23;
public const double SmallSize = 13;
public const double SmallLine = 18;
public const double LabelSize = 12;
public const double BlockGap = 4;
public const double ListGap = 2;

public static double HeadingSize(int level) => level switch
{
    1 => 20,  // H1
    2 => 18,  // H2
    3 => 16,  // H3
    _ => 15   // H4+
};
```

**XAML 模板引用**：
```xml
<!-- ✅ 正确：引用常量 -->
<TextBlock FontSize="{x:Static local:MarkdownStyle.BodySize}" />

<!-- ❌ 错误：硬编码数字 -->
<TextBlock FontSize="15" />
```

### Web (Element Plus 覆盖)

```css
/* src/styles/typography.css */
.pb-body { font-size: 15px; line-height: 23px; }
.pb-small { font-size: 13px; line-height: 18px; }
.pb-label { font-size: 12px; line-height: 16px; }
.pb-h1 { font-size: 20px; font-weight: 700; }
.pb-h2 { font-size: 18px; font-weight: 700; }
.pb-h3 { font-size: 16px; font-weight: 600; }
```

## 常见错误

### ❌ 错误 1：硬编码字号

```xml
<!-- Windows XAML -->
<TextBlock FontSize="14" Text="..." />  <!-- 14 是不存在的字号 -->
```

**修复**：
```xml
<TextBlock FontSize="{x:Static local:MarkdownStyle.SmallSize}" Text="..." />
```

### ❌ 错误 2：行高缺失

```kotlin
// Android Compose
Text("...", fontSize = 15.sp)  // 缺 lineHeight，会用 Material 默认 1.4×
```

**修复**：
```kotlin
Text("...", fontSize = 15.sp, lineHeight = 23.sp)
```

### ❌ 错误 3：等宽字体滥用

```xml
<TextBlock FontFamily="Consolas" Text="用户名：张三" />  <!-- 中文名用等宽会很难看 -->
```

**修复**：
```xml
<TextBlock FontFamily="Segoe UI, Microsoft YaHei UI" Text="用户名：张三" />
```

### ❌ 错误 4：字号层级混乱

```
页面标题 18sp
会话名 17sp    ← 17 是非法字号
摘要 14sp      ← 14 是非法字号
时间 11sp      ← 太小，看不清
```

**修复**：
```
页面标题 18sp (H2)
会话名 16sp (H3)
摘要 13sp (Small)
时间 12sp (Label)
```

## 验收清单

在 PR 中检查以下项：

- [ ] 所有字号来自 {12, 13, 15, 16, 18, 20}，无 11/14/17 等非法值
- [ ] 正文行高 ≥ 23sp（15 × 1.53）
- [ ] 代码/恢复码/token 使用等宽字体
- [ ] 中文文本不使用等宽字体
- [ ] Windows XAML 引用 `MarkdownStyle.*` 而非硬编码数字
- [ ] Android Compose 显式指定 `lineHeight`
- [ ] 标题级别不超过 4 档（H1–H4）
