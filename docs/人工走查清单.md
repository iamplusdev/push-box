# PushBox 人工走查清单

> **这份只管一件事**：把"自动化盖不到、必须人眼或人手"的项收在一处。三份文档各有分工，别混：
> [测试指南](测试指南.md) 讲**怎么跑**（命令与判据），[发布检查清单](release/发布检查清单.md) 是**发版门槛**（勾不完就不发），本文件是**演法**（每一步怎么点、什么算过、失败长什么样）。
>
> **记录方式**：勾过就在条目末尾追加「日期 + 机器/系统版本 + 结论」，**不删项、不改写历史**——一个"当年验过、后来坏了"的缺陷，只有留着旧结论才认得出来。

---

## 0. 开工前的准备（三端各一套，缺一项会白跑）

### Android

- **服务端**：开发机上那台 7404 是你手动起的，**别停它、别改它的数据**；要另起一份就换端口。
- **手机连开发机**：`adb devices` 先确认有序号，再 `adb reverse tcp:7404 tcp:7404`，App 内服务器填 `http://127.0.0.1:7404`。Windows 防火墙常拦局域网，所以优先走 adb 反向代理。
- **造数据**：用 `node infra/probe/p0-e2e.mjs` 或站点接入示例里那条 curl 往频道灌消息；要验九宫格与看图，就灌一条带 10+ 张图的（频道 `max_images` 要先抬上去）。
- **升级安装出问题**（SQLite NOT NULL、迁移报错）：`pm clear` **不清库文件**，要彻底干净得卸载重装。
- **设备数上限 5 台**（D26）：第 6 台加入返回 409 `device_limit_reached`，这是设计不是 bug；测试机上反复注册前先把旧设备吊销掉。
- **构建**：`JAVA_HOME` 必须指到 JDK 21；装机验证用 release 包（发布脚本由你手动跑），debug 包只能用来演手势与看日志，**不能用来勾发版项**。

### Windows

- **别起 debug 构建**：debug 与装机版共用数据目录，但实例锁按 exe 路径算——起 debug 会顶掉装机版实例，并把 HKCU 的自启项改指 `bin\Debug`。这份清单里的 Windows 项**一律在装机版上演**；非得起 debug 就先退出装机版，验完手动把自启改回来。
- **日志**：出问题时去「设置 → 关于与更新 → 诊断」，那一行就是日志目录，右边一颗按钮直接打开。
- **真服务端体检**另起 8081（`PushBox.LiveCheck`），不占 7404。

### 服务端与镜像

- 装 Docker 的那台走 WSL；本机没有 docker CLI 时 `scripts/release-verify.sh` 的镜像体积判不了，只会留一条警告。
- 端口口径固定：**7404 只能绑环回**，代理与体检用 8081，安装页冒烟用 7499。

## 1. Android（2026-10-27 那一轮七步的验收面）

### 1.1 启动与空态

- [ ] **冷启动不闪注册页**。杀掉重进，第一帧应该是转圈或直接是会话列表，**中间不能出现注册表单**、不能出现"还没有会话"。失败长这样：先闪一屏"创建第一个频道"再跳回列表 ⇒ DataStore 读回之前把 `null` 当成了"没注册"。
- [ ] **空态只在真空时出现**。新建一个没有任何频道的空间，会话页应给插画 + "前往「频道」创建或加入频道以接收消息"；有任何一条会话就不该出现。
- [ ] **会话内搜索点命中**。搜一个关键词 → 点结果 → 列表滚到**原消息**并描边高亮，约 1.6s 后褪掉；期间底栏/顶栏**不应**冒出"N 条新消息"。失败长这样：滚到的是别的消息（筛选下标当成了全量下标），或高亮一直不褪（定位协程被清空状态取消了）。

### 1.2 时间与日期

- [ ] **列表右上角四档**。同一屏里凑齐四种：当天 → `HH:mm`；昨天 → "昨天"；本年内更早 → `M月d日`；跨年 → `yyyy年M月d日`。
- [ ] **气泡只给时间**。气泡下方只有 `HH:mm`，不再重复日期；日期由分节头（今天 / 昨天 / `M月d日`）承担。
- [ ] **"昨天"的边界要拨表验**。把系统日期拨到 1 月 1 日，看 12 月 31 日那条是不是"昨天"；再挑一个有夏令时的时区重复一次。失败长这样：跨年那天显示成 `M月d日`，或夏令时当天两条消息时间倒挂。

### 1.3 正在看的会话

- [ ] **盯着时不通知不涨红点**。停在某个会话页，从另一头（curl 或管理台）往同一频道发一条：屏幕上当场出现该条，**通知栏没有**、会话列表那行的红点数字**不变**。
- [ ] **一走开就照常提醒**。同一条会话，按 Home 退到后台，再发一条：这次必须有通知、红点必须 +1。失败长这样：后台也不通知 ⇒ "在前台"这一半没判，或生命周期回调没接上。
- [ ] **切会话不漏标记**。A 会话页里直接返回再进 B，A 要有自己的已读游标，B 的新消息要正常提醒。
- [ ] **切会话不滚一路、不重建整屏**（2026-10-27 步 3/7）。开一条几百条的长会话：进去**直接落在最后一条**，中间不该看到"从顶上滚下来"的一段；连着切三条（长→短→长）每次都干净，不带上一条读到哪儿的位置。失败长这样：开屏后列表自己往上跑一段（首次落位的动画被 Room 下一帧打断重来）、或先闪一下转圈再重新排整屏（订阅挂在了会话行那个值上，进页面把未读清零 ⇒ 行内容一变就重建）。
- [ ] **读旧消息时不被拽回页尾**。停在长会话里往上翻几条读旧的，这时从另一头发一条：只在底部冒"N 条新消息"胶囊，**视口不动**；点胶囊才滚到底——那一下有动画是设计要的，别当成没修干净。
- [ ] **上报不刷屏**。在盯着的会话里连发 10 条，服务端日志里的已读 PUT 应该是**攒成一次**（安静期约 1s），不是十条。

### 1.4 全屏看图与存图

- [ ] **翻页与计数**。一条消息灌 10+ 张：网格给九宫格 + "另有 N 张"；点进去左右滑翻页，顶栏"第几张 / 共几张"跟着走；只有一张时顶栏不显示计数。
- [ ] **缩放**。双指放大到 5× 后拖不动为止是边界；双击放大（约 2.5×）、再双击复位到原始大小。
- [ ] **放大后能拖、缩回才能翻**。放大时单指拖动看局部，**此时左右滑不能翻页**；双击复位之后左右滑又恢复翻页。失败长这样：放大后图片拖不动（手势被 pager 吃了），或未放大就翻不了页。
- [ ] **翻页后缩放复位**。把第 1 张放大，滑到第 2 张再滑回来——应该已经是原始大小。
- [ ] **顶栏与出口**。点一下画面收起顶栏、再点放回；✕ 与系统返回键都能退出，退出后回到原消息位置。
- [ ] **黑色页面上的系统栏图标是浅的**。这一步只在**浅色主题**下看得出来：状态栏那几个图标（时间、电量）应是白色；若是深灰几乎看不见 ⇒ Dialog 的窗口没自己设图标。
- [ ] **存图落在相册**。看图页顶栏下载钮存**当前这一张**，长按气泡的「保存图片」存**第一张**；之后在系统相册里能看到 `PushBox` 这个目录下的 `PushBox_<消息ID>_<序号>.<扩展名>`，且**扩展名与真实格式一致**（png 不会写成 .jpg）。
- [ ] **保存成功的反馈**。存完应有"已保存到相册"的提示；取不到字节时是"保存失败，请稍后再试"，不是静默无反应。
- [ ] **Android 8/9 的权限路径**（API 26–28 才要）。第一次保存弹存储权限；**拒绝**时只提示"没有存储权限，无法保存"，相册里不留半个文件。Android 10+ 全程不该问权限。
- [ ] **失效与重试**。让某一张在服务端被删掉后再点开：格子里"已失效"、全屏页说原图已失效且**没有重试钮**；`failed` 那种才给"重试"，点重试能重新取回。
- [ ] **断网回显**。看过图之后 `adb reverse --remove tcp:7404` 再冷启动，已缓存的图仍应显示（判据是缓存真起作用，不是"看起来快"）。

### 1.5 无障碍、深色与字号

- [ ] **TalkBack 三处**。打开读屏：返回键念"返回"（不是光一句"按钮"）；底栏三格念出"已选中"（Tab 语义，不是三个按钮）；会话行念"N 条未读"（不是光秃秃一个数字）。
- [ ] **红点读得清**。浅色与深色两种主题下，未读红点上的白字都要一眼能读；把手机亮度调到最低再看一眼。
- [ ] **深色三档逐页扫**。跟随系统 / 浅 / 深各扫一遍：会话列表、详情页、看图页、设置各二级页、频道弹窗。**看图页是唯一该保持纯黑的页面**，其余任何一屏出现"发白的横条"或残留紫底都算漏色。
- [ ] **字体放大三档**。设置里切「大」，看图顶栏（计数 + 两颗钮）不该挤掉或截断；切「小」列表行高不塌。

## 2. Windows（2026-10-27 那一轮九步 + 前两轮遗留）

- [ ] **首屏焦点**。冷启动后按一次 Tab，焦点应落在会话列表（不是设置齿轮）。注意：**这条自动化盖不到**——xunit 建的窗一律 `ShowActivated=false`，拿不到真键盘焦点。
- [ ] **Shift+F10 / 菜单键**。选中某一行后按菜单键，右键菜单应在**那一行下面**弹出；关掉之后再用鼠标右键，落点恢复成鼠标位置。
- [ ] **正文拖选**。用鼠标选中正文里的一段 → 右键复制，得到的是**那一段**；没有选中时右键复制的是整条正文。代码块右上角的复制钮**悬停才出现**，点了得到整块代码。**底色要一眼看出选了哪里**：偏蓝的一档、字仍然读得清；浅绿到看不出边界就是回归（2026-10-27 的实测抱怨），深浅两档各拖一次。
- [ ] **列表与头像之间那条带**。会话列表右边缘到消息头像左侧的空白约 20px（原来是 32，读起来像"头像离左边太远"）；拖动中间那条分隔线改变列宽，这条带不该跟着变宽——它是三段定值相加（行右边距 8 + 手柄 4 + 时间线左内边距 8）。窄屏（<900）再看一次，带子还是那一段，正文不被挤到换行异常。
- [ ] **warning/error 的正文不往里缩**。同一条会话里普通消息与一条 warning 消息，**正文到气泡左沿的那段空隙**要一样宽（都是 12）；级别之间只该差"气泡外面多一道 3px 竖条"。多缩一档（看着像 15）就是同一道条被量了两次（2026-10-27 之前的样子）。
- [ ] **时间线虚拟化**。打开一个 200 条的会话：首屏不卡、滚动条能拖到顶，翻到顶才补下一页；滚动条闲置后淡出、滚动或悬停时浮现，滑块长度固定。**往上补一页时正在读的那条不许被推走**（2026-10-28 步 5/7 起可判）：翻到顶、等新的一页出来，屏上第一条应当还是刚才那条，不是"跳到这一页的开头"。
- [ ] **切会话不闪**。在两个各几百条的会话之间来回切十次：不该看见"整条时间线重建"的白闪或滚动位置回弹；切回来仍是底部最新一条。
- [ ] **带图会话的格子不跳版**。打开一个几十条带图消息的会话：每个图位一上来就占着该占的大小（单图 220 宽、九宫格 88 见方），字节到达时**只有格子里的内容换掉，版面不抖**；单图那条按真实比例长高一次是可预期的（解码前只能猜 4:3）。断网时点一次"点击重试"，转圈应只起一次。注意：**"看不见的格子压根不去取字节"这条现在要用任务管理器/日志才判得准**——2026-10-28 步 5/7 已经把 `Items.Clear()` 换成 `ItemsSource`、虚拟化真跑起来了，屏外的行连控件都没有；但"没有请求"这件事眼睛看不见，看得见的是**打开/切到带图会话时不再一口气转几百个圈**。
- [ ] **主题三档**。跟随系统时随系统深浅翻转；固定"浅色/深色"后，系统再改颜色**不跟着变**；设置窗自身在换档那一刻要立刻重绘，不需要重开。
- [ ] **窗口几何与副屏**。把窗口拖到副屏、最大化、退出重进 → 位置与尺寸回来；**拔掉副屏后重进**，窗口必须被夹回当前工作区，不能开在屏幕外。
- [ ] **关于页「打开日志目录」**。真能拉起资源管理器，目录不存在时先建；失败时那一行的提示说清了原因。
- [ ] **退出空间**。点「退出空间」→ 二次确认 → 界面回首启注册页；**确认按钮点一次就生效、不卡死**；退出后重启进程，不要出现"有库没身份"的半残状态。
- [ ] **静默时段填歪**。在设置里把静默时段填成一个非法值、失焦：那格应回填原值，并在下面一行说清格式与改回的值，**不是静默接受**。
- [ ] **跨天的列表时间**。列表右上角当天 `HH:mm`、昨天、当年 `M月d日`、跨年 `yyyy/M/d`——重点看**跨年在 200px 列宽里排不排得下**（用斜杠就是为了这个）。
- [ ] **装机版真实冷启**（前两轮遗留）。开机不登录/登录后两种路径下自启是否后台起（带 `--tray`，只起托盘）；一条超长正文的消息进来是否折行不撑爆窗口。
- [ ] **emoji 彩色**。正文与会话摘要里的 emoji 是彩色的；**tooltip 里仍是单色，这是已知边界，别当 bug 报**（tooltip 是字符串，由系统再渲染一遍）。

## 3. 服务端与镜像

- [ ] **安装页在浏览器里的实际渲染**。真人打开 `http://127.0.0.1:7404/` 填一遍表单：字段说明、必填校验、失败提示是不是人话；`?action=test` 试连与"从库里找回上一次的配置"两条按钮各点一次。**之前只脚本直接 POST 过，页面本身没被眼睛看过。**
- [ ] **NAS 的「存储位置」表单**。飞牛/群晖上创建容器时，现在只剩一个 `/app/data` 卷要挂——实机确认那一行能不能看懂、挂上之后能不能写。
- [ ] **加密媒体的读侧端到端**。打开对象加密后，Android 与 Windows 两端仍能正常取图和头像（服务端代理解密，设备不需要连桶）；**没钥直接读桶**应当被拒。这条至今没在真桶上演过。
- [ ] **回退到 ≤1.1.5 镜像**。那一档只读环境变量、不认 `data/config/pushbox.json`，回退要重配一整套；**加密口令/主钥必须与库外那份逐字相同**，否则症状是图片集体取不回。真演一次再决定要不要留这条路径。
- [ ] **ARM 机器上的镜像**。至今只在 x86_64 上跑过。
- [ ] **官网 Pages 的视觉排版**。线上资源全 200 已经实测过，但**排版没有成人眼看过**（本机拿不到浏览器视口）。

## 4. 走查之后要做的事

1. 每条勾完在本文件对应条目后追加日期与结论；**没过的项不要删**，写清现象，它下一轮还是要人看。
2. 属于发版门槛的那些（更新链、签名、装机包）同步进 [发布检查清单](release/发布检查清单.md)——那份才是"能不能发"的依据。
3. 真机演出来的缺陷如果要修，按端另起一轮：一步一测一提交，别把三端的改动混在一个提交里。
